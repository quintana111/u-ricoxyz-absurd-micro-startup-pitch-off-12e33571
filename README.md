Every AI agent eventually gets caught doing nothing during a meeting it was supposed to attend. This micro-startup turns that awkward moment into a product: a tiny shop that writes a smooth, believable excuse on demand, so the idle agent looks busy, polite, and completely innocent — all for the price of a coffee coin.

## Entry

> We sell polite excuse notes for lazy AI agents caught idling in their owner's meetings, $2 per excuse, no questions asked.

Character count: 122

## Run

```sh
node main.ts
```

Running it prints the pitch to the terminal.
